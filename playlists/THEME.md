# نظام التصميم «ليلٌ مُذهَّب» — سلاسل المشايخ

## الطبقات

1. `theme.css` — توكنات الأساس (ألوان، خطوط، حواف، ظلال، انتقالات) + عناصر مشتركة (hd, btn, crumb, skel, errbox, empty).
2. `ui.css` — مكتبة مكوّنات موحدة، كلها ببادئة `u-`.
3. `icons.svg` — سبرايت رموز: `i-read i-listen i-check i-star i-search i-play i-dl i-clock i-back`.
   الاستعمال: `<svg class="i"><use href="icons.svg#i-read"/></svg>`

## التوكنات (theme.css)

- الخلفيات: `--bg-0` الأساس، `--bg-1` المرفوع، `--bg-2` البطاقات/المدخلات. الألقاب القديمة `--bg --card --card2` باقية.
- الذهب: `--gold-1` باهت، `--gold-2` (اللقب `--acc`)، `--gold-3` فاتح (اللقب `--acc2`)، `--gold-4`.
- دلالية: `--violet` (اللقب `--acc3`)، `--green` (`--ok`)، `--red`.
- حبر: `--ink-1` نص (`--txt`)، `--ink-2` ثانوي، `--ink-3` باهت (`--dim`). كلها تتجاوز WCAG AA ≥4.5 على `--bg-0`.
- حدود: `--line-1` (`--border`)، `--line-2` (`--border2`).
- ظلال: `--e-1 --e-2 --e-3 --e-gold`.
- مسافات: `--sp-1..6` (4/8/12/16/24/32). حركات: `--t-fast --t-med` + `--ease`.
- نصوص: `--font-ui` (IBM Plex Sans Arabic)، `--font-txt` (Amiri). أحجام `--fs-*`.
- الخطوط مستضافة ذاتياً في `fonts/`، تُستورد من `fonts/fonts.css` عبر `@import` أول سطر في theme.css.

## المكوّنات (ui.css)

| المكوّن | الصنف |
|---|---|
| شبكة بطاقات | `.u-grid` |
| بطاقة شيخ | `.u-sh` (.ph صورة/بديل، .nm الاسم، .rw سطر عدّادات) |
| عدّاد أيقونة+رقم | `.u-num` (+`.rd` قراءة، `.ls` استماع؛ `.ok` ✓ اكتمال) |
| صف سلسلة | `.u-sr` (.t عنوان، .acts أزرار، .u-badge «جديد») |
| زر إجراء | `.u-act` (+`.rd`/`.lsn`؛ أدنى ارتفاع 52px) |
| شارة | `.u-badge` |
| شريط رفع | `.u-fbar` > i |
| بحث | `.u-search` |
| ترويسة قسم | `.u-sech` |
| بطاقة بطل | `.u-hero` (h1 + .meta) |
| تقدّم القراءة | `.u-prog` > i |
| زر استكمال/مفضلة | `.u-fav` (.on مفعّل) |
| إدخال | `.u-in` |
| شارة «الكل» | `.u-sh.all` |

## قواعد

- RTL دائماً، اتجاه `dir="rtl"`.
- أهداف اللمس ≥44×44px — لا عنصر تفاعلي أصغر.
- أقل عرض مضمون: 360px (موبايل أولاً).
- حالة تحميل: `.skel` هياكل؛ خطأ: `.errbox`؛ فراغ: `.empty`.
- ظهور تدريجي: `.cin` (fade+rise).
- لا تضيف أنماطاً عشوائية — استخدم التوكنات والمكوّنات أولاً.
